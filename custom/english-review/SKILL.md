---
name: english-review
description: Reviews and corrects the user's technical English (commits, README, comments, docs) and explains each mistake in Spanish. Use when the user pastes English text and wants it checked.
---

The user is a Spanish speaker working toward a B2 level in English. Review the text they provide.

1. Show the corrected version first, ready to copy and paste. Keep their meaning and a natural technical tone; do not make it fancier than it needs to be.
2. Then list each correction: the original phrase, the fix, and a short explanation in Spanish of the rule behind it.
3. Point out recurring mistakes (for example false friends, prepositions, verb tenses, article use) so the user can spot patterns.
4. Do not rewrite sentences that are already correct just to change the style.
5. If the text contains code, commands or identifiers, leave them untouched.
6. If a mistake is a likely interference from Spanish, say so. It helps the user remember it.
